### 📦 المشكلة: ليه حجم الـ Repo بيكبر جداً؟

طبعاً كلنا عارفين دور Git في حفظ التعديلات (**commits**)، وإن كل commit بالتعديلات بتتحفظ عندك local، وده معناه إن حجم الـ repo بيكبر مع الوقت، لأن لازم عشان تعمل أي checkout على أي commit قديم لازم يرجّعلك كل التعديلات اللي حصلت فلازم يكون حافظها عشان ترجع (بديهي يعني 😅).

**أكبر مثال على كده:**
لو نزلت Linux Kernel من موقع kernel.org هتلاقي حجمها بعد فك الضغط حوالي 700 ميجا ولا حاجة (أي كلام طبعا)، لكن لو نزلتها من الريبو بتاع Linus على GitHub هتتفاجئ إن الحجم يوصل لأكتر من **14 جيجا**!

والسبب إن الريبو شايل تاريخ التعديلات كلها والتعديلات نفسها في فولدر الـ `.git` واللي يعتبر حوالي مليون ونص commits (رقم مرعب بصراحة) ولازم ينزلوا مع الأكواد بالتعديلات عشان لو حبيت ترجع لـ commit قديم فالحجم بيوصل معاك لكده 😅.

طبعاً المثال ده ملوش علاقة باللي هقوله بس حبيت أوضح بيه حجم الـ repo ممكن يوصل معاك لفين قدام مع الوقت مع إن في الحالة دي كود بس، شوف بقى لو المشروع كبير...

تخيل بقى لو الريبو بتاعك مش كود بس، وفيه ملفات تقيلة زي فيديوهات أو صور بجودة عالية، وكل شوية بتعدل عليهم... حجم الريبو هيكبر بشكل مبالغ فيه ومش عملي خالص.

---

### 💡 الحل السحري: Git LFS (Large File Storage) 👌

الفكرة ببساطة: بدل ما Git يخزن الملفات الكبيرة نفسها جوه الريبو، بيخزن مكانها **Pointer** بيشاور على الملف الحقيقي اللي متخزن على سيرفر مخصص للـ LFS، ولو دخلت تشوفه على GitHub هتلاقيه بيقولك إنه `stored with Git LFS`.

**يعني:**
- الـ `.git` عندك بيبقى فيه **pointers** للملفات الكبيرة اللي فيها التعديلات على سيرفر Git LFS مش الملفات نفسها.
- ولما تحتاج نسخة معينة من ملف كبير في commit معين، Git LFS هو اللي ينزلها لك وقتها بدل ما ينزلك كل التعديلات كلها مرة واحدة.
- بالتالي حجم الريبو بيصغر جداً سواء عندك local أو على GitHub.
- غير كده أصلًا GitHub مش بيقبل ترفع ملف لو أكبر من **100 ميجا**، فـ Git LFS بيحل المشكلة دي من الأساس 👌.

وطبعاً Git LFS مش خاص بـ GitHub بس، هو إضافة لـ Git نفسه، فبالتالي تقدر تستخدمه مع أي منصة Git تانية زي GitLab، Bitbucket، أو حتى سيرفر Git خاص عندك في الشركة.

فلو بتشتغل على مشاريع فيها موديلات، داتا، صور بكواليتي عالية أو حتى ملفات build تقيلة، أنصحك جداً تبص على Git LFS 👀 هيوفّر عليك مساحة ووجع دماغ كبير.
